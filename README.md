# .github

Organization-level configuration for [**Zanaat**](https://github.com/zanaat-dev).

- [`profile/README.md`](./profile/README.md) — the public organization profile
  shown at [github.com/zanaat-dev](https://github.com/zanaat-dev).
- [`brand/`](./brand) — canonical Lonca (SDK) brand assets (logomark, wordmark, icon,
  social preview). This is the single source of truth; other repositories should
  reference these files rather than keep their own copies. See
  [`brand/README.md`](./brand/README.md) for usage guidelines.
