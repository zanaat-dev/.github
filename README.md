# .github

Organization-level configuration for [**Zanaat**](https://github.com/zanaat-dev), a small workshop of open-source developer tools. [Lonca](https://github.com/zanaat-dev/lonca) and [Baron](https://github.com/zanaat-dev/baron) are sibling projects under it.

- [`profile/README.md`](./profile/README.md) — the public organization profile
  shown at [github.com/zanaat-dev](https://github.com/zanaat-dev).
- [`brand/`](./brand) — **legacy** copies of Lonca's brand assets. Lonca's canonical
  brand now lives in [`zanaat-dev/lonca/brand`](https://github.com/zanaat-dev/lonca/tree/main/brand).
  These files stay because READMEs already published to npm still load them; do not
  delete or rename them.
